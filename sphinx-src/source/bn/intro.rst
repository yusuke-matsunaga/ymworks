概要
~~~~~~~~

Boolean Network は具体的なセルライブラリに依存しないレベルで
多段論理回路を表すデータ構造である．
純粋な意味では組み合わせ論理回路が対象だが，
抽象的な D-FF を含んだ同期式順序回路を表せるようになっている．
具体的には `blif` 形式や `iscas89(.bench)` 形式のベンチマーク回路
の表現に用いることを目的としている．

Boolean Network は非巡回有向グラフ(DAG)として表される．
ノード(節点・頂点)は以下の3種類からなる．

* 外部入力ノード: 外部入力を表す．入枝を持たない．
* 論理ノード: 論理セル(ゲート)を抽象化したもの．論理関数を持つ．
* 外部出力ノード: 外部出力を表す．ただ一つの入枝をもち，出枝を持たない．

枝はその両端のノード間に接続があることを示している．
枝に付加的な属性はないので枝そのものを表すデータ構造は存在しない．

D-FF を含む回路の場合，上記に加えて D-FF の入力と出力に対応するノード
を持つ．
ただし，組み合わせ回路部分だけをみると D-FF の出力ノードは見かけ上，
外部入力ノードと同じである．
同様に D-FF の入力ノードは見かけ上，外部出力ノードと同じである．
そこで，外部入力ノードと D-FF の出力ノードを `入力ノード` とみなす．
同様に，外部出力ノードと D-FF の入力ノードを `出力ノード` とみなす．

さらに，外部ノードは一つの入力しかもたないので，
出力ノードというデータ構造は持たずに，
出力ノードの入力となっているノードを出力ノードの情報として記憶している．

外部入力，外部出力，DFF は名前を持つことが可能である．
ただし，名前は設定された値を保持しているだけなので，
同じ名前が重複して用いられていてもエラーとはならないので注意．
通常の `blif` や `iscas89` 形式のファイルを読み込んだ場合には
そのような異常な状態になることはない．
