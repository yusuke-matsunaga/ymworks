5.2.12. SatOrderedSet¶

class SatOrderedSet

順序符号化で多値を表すクラス

  • 最小値と最大値の間の整数を値として取る．

  • 最小値 <= 最大値であれば負数でも構わない

  • 整数の大小関係に基づく順序関係を持つ．

Public Functions

~SatOrderedSet() = default

デストラクタ

inline int min() const

最小値を返す．

inline int max() const

最大値を返す．

inline SatLiteral var(int val) const

値に対応する変数を返す．

var(val) == True <==> 値が val

パラメータ:

val -- [in] 値 ( min <= val <= max )

inline const std::vector<SatLiteral> &vars() const

値に対応する変数のベクタを返す．

inline SatLiteral pri_var(int val) const

順序符号化された変数を返す．

この変数が true == 値が val 以上 値が min 以上は常に成り立つので val > min となる． つまり var() よりも範囲が一つ短い．

パラメータ:

val -- [in] 値 ( min < val <= max )

inline const std::vector<SatLiteral> &pri_vars() const

順序符号化された変数のベクタを返す．

int val(const SatModel &model) const

SATの解から値を得る．

パラメータ:

model -- [in] SATの解
