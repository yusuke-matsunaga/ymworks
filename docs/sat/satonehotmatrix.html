5.2.11. SatOneHotMatrix¶

class SatOneHotMatrix

one-hot 符号化で多値の組み合わせを表すクラス

elem_size 個の要素のなかから sel_size 個を選ぶ組み合わせを表す． 正確には順列を表す． 内部では elem_size x sel_size の２次元配列(行列)を持つ． 各行，各列の変数に対して one-hot 制約が課されている．
