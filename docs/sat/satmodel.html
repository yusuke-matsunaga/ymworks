5.2.7. SatModel¶

class SatModel

SATの解を表すクラス

意味的には SatLiteral をキーとして対応する SatBool3 値を保持する 辞書と同じである．

結果の値は SatBool3 だが，通常の SAT ソルバの解の場合は True か False のどちらかの2択となっている．
