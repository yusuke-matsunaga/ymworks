4.2.9. ClibPin¶

class ClibPin : public ClibCellElem<CiPin>

セルのピンを表すクラス

共通属性

std::string name() const

ピン名を返す．

ClibDirection direction() const

方向を返す．

bool is_input() const

入力ピンの時に true を返す．

direction() == ClibDirection::input と等価

bool is_output() const

出力ピンの時に true を返す．

direction() == ClibDirection::output と等価

bool is_inout() const

入出力ピンの時に true を返す．

direction() == ClibDirection::inout と等価

bool is_internal() const

内部ピンの時に true を返す．

direction() == ClibDirection::internal と等価

SizeType pin_id() const

ピン番号を返す．

このピンを持つセルを cell とすると． pin = cell.pin(pin_id); pin_id = pin.pin_id() が成り立つ．

入力ピンの属性

SizeType input_id() const

入力ピン番号を返す．

入力ピンもしくは入出力ピンの時のみ意味を持つ． このピンを持つセルを cell とすると． pin = cell.input(iid); iid = pin.input_id() が成り立つ．

ClibCapacitance capacitance() const

負荷容量を返す．

ClibCapacitance rise_capacitance() const

立ち上がり時の負荷容量を返す．

ClibCapacitance fall_capacitance() const

立ち下がり時の負荷容量を返す．

出力ピンの属性

SizeType output_id() const

出力ピン番号を返す．

出力ピンもしくは入出力ピンの時のみ意味を持つ． このピンを持つセルを cell とすると． pin = cell.output(oid); oid = pin.output_id() が成り立つ．

ClibCapacitance max_fanout() const

最大ファンアウト容量を返す．

ClibCapacitance min_fanout() const

最小ファンアウト容量を返す．

ClibCapacitance max_capacitance() const

最大負荷容量を返す．

ClibCapacitance min_capacitance() const

最小負荷容量を返す．

ClibTime max_transition() const

最大遷移時間を返す．

ClibTime min_transition() const

最小遷移時間を返す．

Expr function() const

論理式を返す．

定義されていない場合には Expr::is_invalid() == true となる式を返す．

Expr tristate() const

tristate 条件式を返す．

定義されていない場合には Epxr::is_invalid() == true となる式を返す．

内部ピンの属性

SizeType internal_id() const

内部ピン番号を返す．

内部ピンの時のみ意味を持つ．

Public Functions

ClibPin() = default

空のコンストラクタ

不正値となる．

inline ClibPin(const CiCell *cell, const CiPin *impl)

内容を指定したコンストラクタ

パラメータ:

  • cell -- [in] 親のセル

  • impl -- [in] 本体

~ClibPin() = default

デストラクタ
