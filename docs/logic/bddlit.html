1.2.6.7. BddLit¶

class BddLit : public BddBase¶

BDD のリテラルを表すクラス

  • ブール論理の世界においてはリテラルとは変数とその否定のみ

  • 実際にはリテラル関数を表すBDDを用いている．

Public Functions

BddLit() = default¶

空のコンストラクタ

不正な値となる．

explicit BddLit(BddMgrHolder &mgr, SizeType varid, bool inv = false)¶

マネージャと変数番号を指定したコンストラクタ

  • mgr が nullptr の時は std::invalid_argument 例外が送出される．

パラメータ:

  • mgr -- [in] マネージャ

  • varid -- [in] 変数番号

  • inv -- [in] 反転属性

    • false: 肯定(反転なし)

    • true: 否定(反転あり)

explicit BddLit(const BddVar &var, bool inv = false)¶

BddVar と反転属性を引数にとるコンストラクタ

  • var が不正値の時は std::invalid_argument 例外が送出される．

パラメータ:

  • var -- [in] 変数

  • inv -- [in] 反転属性

    • false: 肯定(反転なし)

    • true: 否定(反転あり)
