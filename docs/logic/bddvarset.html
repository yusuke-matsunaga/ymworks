1.2.6.6. BddVarSet¶

class BddVarSet : public BddBase¶

Bdd を用いて変数集合を表すクラス

実際には変数を表す関数の論理積を用いている． 空集合を表す場合には定数1を用いる． 定数0は用いない．

Public Functions

explicit BddVarSet(const std::vector<BddVar> &var_set = std::vector<BddVar>{})¶

要素のリストを指定したコンストラクタ

  • var_set を省略した場合には空集合となる．

  • var_set の要素に不正な BddVar が含まれている場合， std::invalid_argument が送出される．

  • var_set の要素に相異なる BddMgr の BddVar が含まれている場合， std::invalid_argument が送出される．

パラメータ:

var_set -- [in] 変数のリスト
