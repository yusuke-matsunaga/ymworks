1.2.6.4. Bdd¶

class Bdd : public BddBase¶

BDD を表すクラス

  • 基本的に個々の Bdd は一つの BddMgr に属す．

  • 例外は invalid な Bdd で関連する BddMgr を持たない．

  • Bdd 間の演算は同じ BddMgr に属するもののみ可とする．

  • 異なる BddMgr に属する Bdd の演算は std::invalid_argument 例外を 送出する．
