1.2.1.2. Literal¶

class Literal

リテラル(変数番号＋極性)を表すクラス

内部では変数番号を2倍したものに極性フラグを加算している． 極性は肯定が 0 , 否定が 1 と見なす． 反転しているかどうかを表すブール値と考えれば良い．
