1.6. NPN変換を扱うサブグループ¶

class NpnMap¶
#include "ym/NpnMap.h"

NPN変換の情報を入れるクラス

具体的には

  • 入力変数の写像

  • 入力変数の反転属性

  • 出力変数の反転属性 の情報を持つ．入力変数の写像は N -> N の順列となる．

    参考

    NpnVmap

Public Functions

NpnMap() = default¶

空のコンストラクタ．

内容は不定

explicit NpnMap(SizeType ni)¶

入力数を指定したコンストラクタ

定義域と値域のサイズは同じになる． 恒等変換になる．

パラメータ:

ni -- [in] 入力数

NpnMap(SizeType ni, SizeType ni2)¶

写像前と後の入力数を指定したコンストラクタ

内容は不定

パラメータ:

  • ni -- [in] 写像前の入力数

  • ni2 -- [in] 写像後の入力数

NpnMap(const NpnMap &src)¶

コピーコンストラクタ

パラメータ:

src -- [in] コピー元のオブジェクト

代入演算子

パラメータ:

src -- [in] コピー元のオブジェクト

戻り値:

自分自身への定数参照を返す．

~NpnMap() = default¶

デストラクタ

void clear()¶

内容をクリアする．

入力の変換内容は不正な値になる． 出力の極性は反転なし

void resize(SizeType ni)¶

入力数を再設定する．

写像前と写像後の入力数が等しい場合． 以前の内容はクリアされる．

パラメータ:

ni -- [in] 入力数

void resize(SizeType ni, SizeType ni2)¶

入力数を再設定する．

パラメータ:

  • ni -- [in] 写像前の入力数

  • ni2 -- [in] 写像後の入力数

void set_identity(SizeType ni, bool oinv = false)¶

恒等変換を表すように設定する．

パラメータ:

  • ni -- [in] 入力数

  • oinv -- [in] 出力を反転する時 true にするフラグ

inline void set_imap(SizeType src_var, SizeType dst_var, bool inv)¶

入力の変換内容の設定

パラメータ:

    • true: 反転あり (負極性)
