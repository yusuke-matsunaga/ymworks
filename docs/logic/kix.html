1.2.3.6. KIX (Kernel Intersection eXtracter)¶

class KIX

Kernel Intersection Extraction を行うクラス

実際にはただの関数の集まり

Public Static Functions

static std::vector<CoverInfo> extract(const std::vector<CoverInfo> &cover_list)

共通な論理式を括りだす．

括りだした新しいカバーは結果のカバーの末尾に追加される． 新しいカバーの出力に対応する入力はもとの入力の後ろに追加される．

パラメータ:

cover_list -- [in] カバー情報のリスト

戻り値:

結果のカバーのリストを返す．
