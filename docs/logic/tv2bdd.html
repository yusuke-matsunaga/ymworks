1.2.4.5. Tv2Bdd¶

class Tv2Bdd

TvFunc を Bdd に変換するクラス

実際にはただの関数群

参考

TvFunc, Bdd

Public Static Functions

static Bdd gen_bdd(const TvFunc &f, BddMgr &mgr)

TvFunc を BDD に変換する．

パラメータ:

  • f -- [in] 対象の関数

  • mgr -- [in] BDDマネージャ

static Bdd gen_bdd(const TvFunc &f, BddMgr &mgr, const std::vector<BddVar> &var_list)

BDD に変換する．

  • f の i 番目の変数を var_list[i] に対応させる．

  • var_list.size() >= input_num() でなければ std::invalid_argument 例外を送出する．

パラメータ:

  • f -- [in] 対象の関数

  • mgr -- [in] BDDマネージャ

  • var_list -- [in] 変数リスト
