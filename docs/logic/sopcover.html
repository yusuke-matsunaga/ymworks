1.2.3.5. SopCover¶

class SopCover : public SopBase

カバー(積和形論理式)を表すクラス

中身は positional cube matrix 表現を用いたビットベクタ

ビットベクタの内容は一旦，設定されたら変わることはない

キューブはワードレベルの順序で整列しているものと仮定している

実装としてはパタンの実体は SopBase::Chunk が持つ．
