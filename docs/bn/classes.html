2.2. クラス一覧¶

ネットワーク全体を BnModel が表す． ネットワーク中のノード(入力ノード，論理ノード)は BnNode が表す． D-FFの情報は BnDff が表す． これらのクラスはすべて実装クラスへのスマートポインタとなっており， ユーザーアプリケーション側でリソースの管理を行う必要はない． これらのオブジェクトのコピーはポインタのコピーと同程度のコストで 行える． 逆にいうと一つでも BnNode や BnDff のオブジェクトが残っていると それを含むネットワーク全体のリソースは開放されない． BnNode や BnDff は std::vector<> を用いてリスト構造を作る ことができる．上述のように BnNode や BnDff のコピーのコストは 小さいので問題はないが， BnModel や BnNode が内部に持っている リストをそのまま利用した BnNodeList と BnDffList というクラス も用意されている． こちらのほうがよりオーバーヘッドが少ない．
