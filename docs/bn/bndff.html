BnDff¶

class BnDff¶

BnModel のDFFを表すクラス

以下の情報を持つ．

  • ID番号

  • 出力のノード

  • 入力のノード

  • リセット値

空のコンストラクタで作られたインスタンスは不正値となる． その場合，is_valid() は false を返し， is_invalid() は true を返す． それ以外のメンバ関数の呼び出しは std::logic_error 例外を送出する．

公開されているメンバ関数はすべて const であり，内容を変更することは できない．
