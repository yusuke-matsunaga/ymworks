1. AIG
基本的な概念は abc の AIG と同一だが，実装に関しては一切，参考にしてい
ない．
AIGとは AND-INVERTER-GRAPH の略で，2入力ANDゲートとインバーターのみで
論理回路の構造を表すものである．
ただし，正確には単純なDFFも含むので同期式順序回路を表すことができる．

以下に，ymworks で用いる AIG の部品(クラス)について説明する．

1.1 AigNode
2入力ANDゲートを表すクラス．
ただし，入力ノードも同一のクラスにしておいたほうが都合がよいので，
入力ノードを表す時もある．その場合にはファンイン(入力)を持たない．
さらに，DFFの出力を擬似入力とみなすこともできるのでDFFの出力
を表す時もある．
一方，出力は AigNode ではないので注意すること．
AigNode は共通な情報としてID番号，参照回数とファンアウト情報を持つ．
ID番号は唯一な番号であるが，場合によっては変わることがあるので数字その
ものに意味はない．
参照回数は現在，参照されている回数を保持している．
単純には保持しているファンアウト情報の数と等しくなるが，
実際には存在していても用いられていないノードの場合，
そのファンインのノードを参照しているとはみなさないので
この参照回数はファンアウト数よりも少ない場合がある．
ファンアウト情報に関しては後述する．

ANDゲートを表す場合は2つのファンインを表す枝(AigEdge)を持つ．
ここで枝と言っているものは AigNode へのポインタと反転属性を組み合わせ
たものである．

外部入力を表す場合は入力番号を持つ．これはANDゲートのファンインのフィー
ルドを用いる．

DFF出力を表す場合はDFF番号を持つ．これはANDゲートのファンインのフィー
ルドを用いる．

1.2 AigEdge
前述のように AigNode と反転属性を組み合わせたもの．
単純にはポインタとbool型の2ワード必要になるが，ポインタの下位ビットは
常に0であることが保証されているのでそこに反転属性を埋め込んでいる．
APIとしては AigNode へのポインタと独立した bool 変数があるものとみなさ
れる．
AigEdge に対する演算としては極性を反転させる演算子 (~) および反転属性
との掛け算 (*) がある．
また，正極性・負極性の枝を返すメンバ関数も用意されている．

1.3 AigTerminal
出力を表すもの．実は AigEdge とほぼ同じものだが，AIG全体としてどの枝が
出力なのかを明示するためにこのクラスを用いている．
前述の参照回数はこの AigTerminal からファンイン方向にたどって到達可能
なノードのみが考慮される．
ある意味，終端をピンどめするためのクラス．
補助的な情報として，外部出力なのかDFFの入力なのかを区別するフラグと
出力番号/DFF番号を持つ．

1.4 FoInfo
AigNode のファンアウト先は他の AigNode か AigTerminal となる．
FoInfo はそれらを統一的に扱うためのラッパクラスである．
具体的には，AigNode なのか AigTerminal なのかを表すフラグと
AigNode/AigTerminal へのポインタを持つ．
実装としてはポインタ1つ分のサイズのみを使用する．
AigNode にファンアウトしている場合，どちらのファンインとなっているかの
情報があったほうが便利だが，AIGでは同一の構造を持つノードを共有する
都合上，ファンインの順序に正規化ルールを施している．
そのため，他のファンインが変わった場合にファンインの順序が変わる場合が
あり，ファンアウト先の情報としてファンインの位置を持っていると管理が
煩わしい．そのためファンアウト先のノードの情報のみを保持している．

1.5 AigMgr
AIG全体を管理するオブジェクト．
ノードの生成などを行う．
AigMgr の API を用いている限り，ファンアウト情報や参照回数などの情報の
整合性は常に保たれている．
AigMgr は上位レベルの API を提供するためのクラスで低レベルの実装は
AigMgrImpl が担当している．
